Open the browser DevTools, go to the Network tab, select Img, reload the page, and then scroll slowly.

Eager Loading

This image uses loading="eager". The browser can request this image immediately while loading the page.

Lazy Loading - Image 1

This image uses loading="lazy". The browser can delay downloading it until it gets close to the viewport.













Lazy Loading - Image 2

Lazy Loading - Image 3

Another image using native HTML lazy loading.













Lazy Loading - Image 4

Watch the Network tab while scrolling toward this image.













What Happens?

1. Browser requests the HTML page from the server.

2. Browser parses the HTML.

3. Browser discovers the image URLs.

4. Eager images can be downloaded immediately.

5. Lazy images can wait until they are close to the viewport.

6. Browser sends an HTTP request for the image.

7. Server sends the image data back.

8. Browser displays the image.
